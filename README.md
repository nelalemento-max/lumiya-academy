# Lumiya Academy

**Aprender hoy. Crecer para siempre.**

Plataforma educativa web bilingüe y escalable para niños y familias.

## Primera etapa

El primer curso será **Mecanografía divertida** (nombre interno: **LumiType**), con:

- teclado y manos en pantalla;
- guía visual del dedo correcto;
- ejercicios progresivos;
- medición de precisión y velocidad;
- niveles, estrellas, rachas e insignias;
- perfiles infantiles y seguimiento familiar.

## Visión

Lumiya Academy crecerá con cursos de lectura, escritura, ortografía, matemáticas, inglés, ciencias, apoyo escolar, escuela en casa, creatividad y tecnología.
